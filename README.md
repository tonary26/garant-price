# Изменения страницы прайса ГАРАНТ

## Просмотр

Откройте http://127.0.0.1:8765/price.php, пока локальный сервер работает.
Повторный запуск из этой папки:

```powershell
php -n -S 127.0.0.1:8765 preview-router.php
```

Это локальный предпросмотр страницы и её меню, собранный из исходных шаблонов без исполнения архивного PHP, подключения к базе и отправки писем. В заголовок подставлены публичные название страницы и телефон. Остальные страницы сайта в предпросмотр не входят. Старые внешние ссылки ведут на исходный сайт.

## Установка в тестовую среду

Сохранить резервную копию исходного price.php. Перенести только:

- price.php
- assets/price-contact.css
- assets/price-contact.js
- price-request.php

Шапка, меню, футер и существующие формы остаются исходными. Страница использует существующие короткие PHP-теги и требует short_open_tag=On, как исходный сайт. Старые mysql_* вызовы в шапке требуют существующего окружения сайта; PHP 8 не сможет исполнить их без отдельной миграции. Для этого предоставлен независимый локальный предпросмотр.

Новая форма использует отдельный обработчик: исходный form_2.php считает непустое поле email причиной прекращения обработки. Новый обработчик принимает имя, телефон и email, проверяет данные и возвращает JSON. Для доставки писем задать переменные окружения GARANT_PRICE_RECIPIENT и GARANT_PRICE_SENDER (по одному адресу) и настроить серверный mail(). Без настройки возвращается явная ошибка 503. GARANT_PRICE_PREVIEW не включать на публичном сервере. Локальный router включает его только для теста и явно сообщает, что данные не отправлены. Доставка писем не проверялась.

## Проверки

- Содержимое всех шести исходных таблиц побайтово сохранено.
- Раскрытие/скрытие цены работает.
- В браузере проверены обе кнопки, ввод, тестовая отправка, Escape, автоматический фокус и возврат фокуса.
- На 320, 390, 768 и 1440 px нет горизонтального переполнения страницы; широкие таблицы прокручиваются внутри.
- Сервер отклоняет неверные данные (422) и GET (405).
- PHP lint и JS syntax check прошли; ошибок выполнения JS в проверке нет.
- Существующие серверные формы не отправлялись и не проверялись с рабочей базой.

## Результат проверки исходного архива

Архив содержит 4623 записи, около 299 МБ после распаковки, включая старые админки, phpMyAdmin, FCKeditor, 1277 вложенных ZIP в rus/files и настройки подключения к базе. Путей с выходом за каталог не обнаружено. Выполнен статический поиск опасных PHP/JS конструкций; просмотренные совпадения относятся к старым библиотекам и обычному коду. В просмотренном коде страницы и её зависимостей явного вредоносного загрузчика не обнаружено.

Это ограниченная статическая проверка, а не антивирусное заключение: вложенные архивы и все бинарные документы не анализировались. Архив не доказывает добросовестность отправителя тестового задания. Полный исходный архив, настройки базы и админки в эту поставку не включены.
